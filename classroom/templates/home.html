Program a robot dog.

A real Unitree Go2, simulated well enough that the same five lines of Python drive both. Students write dog.move(), watch it walk, and keep the code that made it happen.

What a session looks like

from go2 import Go2

dog = Go2(sim=True)
dog.move(vx=0.4)     # walk forward
dog.wait(3)
dog.backflip()       # show off
print(dog.pose())

The dog renders in the notebook beside the code. Nothing is pretend about the API: Go2(sim=False) is the same object pointed at real hardware, which is the whole design — students learn one thing, not a teaching toy they later have to unlearn.
